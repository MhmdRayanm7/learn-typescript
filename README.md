Learning exercises from the [Boot.dev Learn TypeScript](https://www.boot.dev/courses/learn-typescript) course.

The course focuses on static typing, type-safe development, advanced TypeScript concepts, and modern development tooling.

## Course Topics

- Basic types and type inference
- Typed functions
- Union and intersection types
- Arrays, objects, and tuples
- Interfaces and enums
- Type narrowing
- Classes and access modifiers
- Utility types
- Generics
- Conditional types
- Local TypeScript development

## Repository Exercises

- TypeScript compiler configuration
- Strict type checking
- Type declaration files (.d.ts)
- Typing legacy JavaScript modules
- JavaScript and TypeScript interoperability
- TypeScript compilation
- Vite project setup
- DOM element typing

## Getting Started

```bash
npm ci
npm run dev
```

Build the project:

```bash
npm run build
```
